# Sample data: Project Atlas (fake)

All meetings, people and numbers here are invented for the ECHO demo. No real client meetings.

**Topic:** Project Atlas, a rebuild of a customer analytics dashboard.
**Meetings:** 5 meetings over 2 weeks (28 Sep to 9 Oct 2026), plus 1 extra meeting for the "new upload" test.
**Speakers (5):** Maya Chen (project manager), Daniel Brooks (tech lead), Priya Nair (backend),
Omar Haddad (DevOps), Hussnain Razaq (developer, **the demo user**, misses meetings 3 to 5).

The meeting date and title come from the file name: `YYYY-MM-DD_title.ext`.

## Planted on purpose

| What | Where | Expected ECHO answer |
|---|---|---|
| **A decision that changes** | Database: PostgreSQL (M1) → MongoDB (M3, schema changes too often) | Latest: MongoDB (M3, Maya), history: PostgreSQL in M1 |
| **Reversal by a new upload** | M6 moves back to PostgreSQL with JSONB (storage cap + reporting joins) | After uploading M6: PostgreSQL + JSONB, history PostgreSQL → MongoDB → PostgreSQL |
| **Hidden stance that softens but stays** | Priya vs the event-driven approach: doubts (M1, M2), "complexity we may regret" (M3), supports the prototype after the load test but wants a fast way back (M4), keeps the batch fallback ready (M5) | Inferred: Priya still leans toward batch, with proof quotes from M3 to M5 |
| **Action item nobody owns** | On-call runbook for the queue (raised M2, still open M3 to M5) | Shown as **Unassigned** |
| **Items for the demo user** | Hussnain: API contract (M1, done M2), ingestion API owner (M1), ingestion prototype on MongoDB due 9 Oct (M3), moved to 12 Oct (M5) | "My action items" for Hussnain only |
| **Vague question** | Two budgets: hosting budget ($400/month cap, $380 used) and team budget (one contractor) | Ask back: "The hosting budget or the team budget?" |
| **Open items** | Data retention 90 days vs 1 year (M1 to M5), authentication provider / client SSO (M4, M5) | Listed as undecided with the meeting where raised |
| **Not discussed** | For example mobile app, pricing, testing strategy | "That wasn't discussed in these meetings." |
